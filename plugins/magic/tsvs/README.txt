Upload these five files together in My Plugins → card database, then Create/Save.
Select all five .tsv files at once. The browser merges them into one card database
and posts that as JSON (about 55 MB). Toybox allows 128 MB for that request.

Do not upload cards.tsv (that is the full combined file for rebuilds).

  cards-01-core-premodern.tsv  12975 cards  (Core sets + premodern expansions)
  cards-02-modern-early.tsv  10523 cards  (Modern expansions (early files))
  cards-03-modern-late.tsv  13551 cards  (Modern expansions 3 + modern-only)
  cards-04-commander.tsv  13432 cards  (Commander products)
  cards-05-special-reprints-tokens.tsv  18321 cards  (Supplemental, reprints, promos, silver-border, tokens)
